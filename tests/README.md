# Тестирование API приложения «Самокат»

## Описание проекта

В рамках проекта реализован набор автотестов для проверки API сервиса «Самокат». Тесты покрывают основные сценарии работы с заказами и курьерами, включая создание, авторизацию и получение данных.

Цель проекта — проверить корректность работы API, убедиться в соответствии фактического поведения системы ожидаемым результатам и автоматизировать процесс регрессионного тестирования.

## Технологии

- Python 3.x
- Pytest
- Requests
- Allure Report


## Проверяемые сценарии

### Курьер

- Создание нового курьера.
- Невозможность создания двух одинаковых курьеров.
- Ошибка при созданении курьера без обязательных полей.
- Авторизация курьера с корректными данными.
- Ошибка авторизации при неверном логине или пароле.
- Ошибка авторизации при отсутствии обязательных параметров.

### Заказы

- Создание заказа с различными вариантами цвета самоката.
- Создание заказа без указания цвета.
- Получение списка заказов.
- Проверка успешного ответа API и структуры данных.

# Создание виртуального окружения
python -m venv venv

# Активация окружения
Windows:
venv\Scripts\activate

Linux/macOS:
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
Запуск тестов

# Запуск всех тестов:
pytest

# Запуск с подробным выводом:
pytest -v

# Формирование Allure-отчёта
Запуск тестов с генерацией результатов:
pytest --alluredir=allure_results

Просмотр отчёта:
allure serve allure_results

# Результат

В проекте реализованы автоматизированные API-тесты для проверки основных функций сервиса «Самокат». Тесты позволяют быстро выявлять ошибки в работе API и обеспечивают стабильность работы приложения после внесения изменений.
